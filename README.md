# CrraBloom_PPG
CrraBloom_PPG (or the CrraBloom Physics Program) is an open-source physics simulator written in the programming language C with Raylib.

# CrraBloom_PPG dependences:
- raylib
- Git

# Recommended:
- CMake
- And more!

# How to compile:
1. Clone the repo:
´´´
git clone https://github.com/RafaDEV99/CrraBloom_PPG.git
cd CrraBloom_PPG
´´´
2. Create a build folder:
´´´
mkdir build && cd build 
´´´
3. Compile:
´´´
cmake ..
make
´´´
